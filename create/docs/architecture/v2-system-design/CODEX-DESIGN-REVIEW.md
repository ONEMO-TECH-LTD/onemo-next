Second, make the non-optional objects first-class: `design_sessions`, `image_sources`, `design_checkpoints`, `design_revisions`, `proof_artifacts`, `share_artifacts`, `owned_effects`, `collections`. Third, add three missing contracts before touching more UI: `CreateBootstrapState`, `CompatibilityContext`, and `CheckoutIntent` from an approved revision. Fourth, make the viewer layer carry the real product semantics: safe areas, backside viewpoints, attachment-system state, receiver compatibility, and pair/bundle context.
