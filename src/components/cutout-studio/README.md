# Cutout Studio

Cutout Studio is the current V1 cutout editor. The portable product package is rooted at `CutoutStudio.tsx` and `flow.ts`; the `/cutout-lab` route supplies only the current development mount, calibration panel, phone diagnostics, and optional Eruda console.

## Ownership

- `CutoutStudio.tsx` renders the existing UI and captures gestures.
- `flow.ts` owns state, actions, cancellation, history, tool ordering, Preview, Save, and `CutoutResult` export.
- `finish.ts` adapts accepted masks and vectors to the shared effect preparation and compositor pipeline.
- `src/lib/cutout-grabcut` owns the single OpenCV GrabCut provider.
- `src/lib/mask-tools` owns Paint swaths, Autotune, mask smoothing, and mask booleans.
- `src/lib/cutout-studio/result.ts` owns the portable `cutout-result/v1` manufacturing handoff.

There is one shared Vector resolver for AI, GrabCut, and Paint. AI and GrabCut begin with the selected Cutout preset. Paint begins from its calibrated Paint baseline; deliberate later Vector changes use the same resolver as every other source.

## Processing

- Detect: U2NetP primary, lazy Silueta fallback, then a visible flood-fill degradation.
- GrabCut: OpenCV standalone or refinement, followed by the same edge-finishing and preparation path as Detect.
- Paint: brush geometry, loop closing, Autotune, and mask smoothing; erase is direct inverse brush subtraction.
- Output: original upload pixels drive the live result, Preview, Save, and exported result. The editor mask remains bounded for interaction performance.

Current calibrated defaults are edge finish `12px`, Paint Autotune `50%`, Paint mask smoothing `20%`, and loop close `50%`.

## Portable boundary

`scripts/generate-cutout-studio-closure.mjs` records the exact source, dependency, asset, test, owner, and public API closure in `closure.generated.json`. The route files are deliberately excluded from that portable closure.

`CutoutResult` contains the final `VShape`, manufacturing `Contour` in millimetres, artwork identity, mask identity, scale, and input recipe. It is the handoff boundary for a later UI shell or Grid engine. Cutout Studio does not bind to the in-flight Grid implementation.

## Verification

Run the focused unit tests plus the committed browser preservation, detector, flow, output, and GrabCut journeys. Regenerate the closure after any portable source or dependency change and commit it only when the generated bytes match the current package.
