## 1. The ruler (Dan, 2026-08-23)

- **No law measurement is finer than 1 mm.** Sizes, flap, clearance, concessions: whole millimetres. Compute measures one signed disc clearance per anchor and converts it to the ruler exactly once: `clearanceMM = Math.floor(rawClearanceMM + 0.5)` — `[-0.5, 0.5)` reads 0, `[0.5, 1.5)` reads 1, `[-1.5, -0.5)` reads −1. Nothing below the ruler decides a law; nothing below the ruler is displayed as law. Reading of Dan's ruling, settled by the team (QA and Meta accepted): a clearance the ruler cannot see is not a measurement, so it is not a gap.
- **Shape sizes are even millimetres** (24, 26, 28 …). This rules the size ladder only; supplied contour coordinates, Centre outputs, phases, lattice nodes and mesh samples may stay fractional internally — they are measured, never ruled.
- Consequence: no sub-millimetre policy tolerance and no new geometry quantum anywhere in Law; the ruler conversion in `measureWrap` is the only place a measurement becomes a law value. The frozen Centre path's numerical internals (2 mm mesh, 0.01 mm key quantum, Newton thresholds, the 0.001 mm integer seat prescreen, float epsilons) are measurement machinery, not policy allowances; they stay as they are and never enter a law comparison.

## 2. The three laws

1. **CENTRE** — at each even size, derive one governed centre from the scaled shape alone (Box, Core, Weight, Deep, Top, Masses with governor — the existing numeric ruler, unchanged), place the lattice rigidly by parity (odd line count: node on the centre; even: gap on it), and consider all four parity placements. The centre may change with size; it never changes because magnets landed.
2. **WRAP** — for every lattice anchor, Compute measures the nearest distance `d` to the complete supplied boundary (outer and holes) and whether the anchor centre is in material; one signed raw clearance `rawClearanceMM = pointInMaterial(anchor) ? d − spotRadiusMM : −(d + spotRadiusMM)` is converted once to the ruler (§1). The final Law `seated` population is exactly the anchors with `clearanceMM ≥ 0`. For belt anchors `requiredFlapMM = max(0, clearanceMM)`; the candidate's required flap is the maximum belt value; lawful when `requiredFlapMM ≤ flap`. Seat and Wrap therefore consume one boundary, one distance and one ruler value; no raw sub-millimetre sign decides Law admission. `0` = seated and clearance reads 0 on the ruler. Auto returns the smallest whole-mm allowance that makes the layout lawful, never a scan.
3. **MAGNET-QUANTITY SCALING** — in each band, evaluate every even size and all four placements; publish each next available magnet count once, at the smallest even size where a placement with that count is centred and wrapped. Counts strictly increase (jumps are valid). A count accepted in a lower band never reappears above. Every candidate size is evaluated; coverage over the even-size ladder is complete by construction. No size between even sizes is ever followed, searched or published.

Tie rule: among placements equal on centre, wrap, count and flap, vertical eliminates horizontal; remaining ties are all returned. No score, weight, fallback or hidden winner anywhere. Refusals are typed; fixed-size/manual inspection returns measured whole-mm concessions.

### 5.2 `compute.ts` — geometry only

- `seat.ts`: `bbox`, `latticeAt`, `makeSeatPredicate` unchanged as the frozen Centre path's placement prescreen (float + 0.001 mm integer kernel, outer-only; internal geometry, not a law value), circle path deleted, `measureCentrePlacements` (all four), `splitPerimeter`, `measureExtremeCorners`, `edgeDistMM`, `pointInMaterial(contour, p)` (outer + holes, float winding), `scaleContour(base, evenSizeMM)`. `measureParity(seated, target, pitch)` preserves the frozen Centre line identity: per-axis line count keys are `Math.round(coordinate / 0.001)`; odd lines require a node on the governed centre and even lines the gap. It returns neutral `ParityMeasurement`; the larger raw axis miss is converted once with `Math.floor(rawCentreErrorMM + 0.5)` solely for report-only `centreErrorMM`.
- `centre-evidence.ts`: `safeSegments`, `centroidOf`, `measureCentreBranches` — unchanged.
- `wrap-measurement.ts` (renamed from `contact-root.ts`): `measureWrap(contour, lattice, pitchMM, spotRadiusMM): { seated: Pt[]; belt: Pt[]; wrapMeasurement: WrapMeasurement }` — one private Compute result; the supplied segments, outer + holes, are the sole geometry. After Centre selects a phase, Compute regenerates that bounded lattice and, for every node: nearest distance `d` to every outer and hole segment (`edgeDistMM`), `pointInMaterial(node)` (inside outer, outside every hole), `rawClearanceMM = inMaterial ? d − r : −(d + r)`, `clearanceMM = Math.floor(rawClearanceMM + 0.5)` — the one conversion, one per-anchor clearance record. It filters `seated` = nodes with `clearanceMM ≥ 0`, derives `belt = splitPerimeter(seated, pitchMM).belt` (the existing ≤4-neighbour rule), then reduces over the belt from the same records — no boundary distance is recomputed: `requiredFlapMM = max(0, clearanceMM)` over the belt; witnesses: for each belt disc, every distinct outline point tied for the minimum distance under the same double computation — exact native equality identifies a tie, no tolerance creates one; stable ring/segment traversal order, identical projected coordinates deduplicated; duplicate binders never change `requiredFlapMM`. `WrapMeasurement` is the policy-facing union and does not duplicate the populations; `PlacementCandidate.seated`, `.belt` and `.wrapMeasurement` are copied from that one result in the same assembly step, on the refused path as well as the measured one, so a refused candidate never needs fabricated populations or a second computation. Coverage and MagnetPlan consume `seated` only after this result exists. There is no seat refusal: the final population is defined by the ruled filter.
- `identity.ts`: `contourIdentity(contour)` = canonical JSON of the ordered coordinates (no hashing library); `boundaryTruth` = `{ rule: 'supplied-final-contour', contourIdentity }`.

Signed seat/Wrap clearance is converted only in `measureWrap`; seat, fixed, Auto, Free/manual and the band walk all consume that one signed integer. Compute converts the larger-axis Centre miss once with `Math.floor(rawCentreErrorMM + 0.5)` solely for the report-only `centreErrorMM` concession; it never decides candidate or rung admission. No other place rounds, clamps or tolerates.

### 5.3 `logic.ts` — the three rules, integer comparisons only

Logic receives the complete measurement union and returns decisions. A geometry refusal passes through unchanged — Logic never invents `requiredFlapMM` or `allowedFlapMM`; only a `measured` value enters fixed/Auto integer comparison. `evaluateWrap(measurement, policy)` is the one judgement; `computeGrid` (Free/manual) and `reduceBandLadders` (band) both call it on the same `WrapMeasurement` shape, so fixed, Auto, manual and rung can never disagree. Its scaling inputs are the integer `sizeMM`, the integer `requiredFlapMM`, parity evidence, populations and identities; native integer comparison is authoritative because the ruler conversion already happened in Compute. Logic imports nothing from compute.

```ts
export function governMass(...)            // unchanged
export function centeringAnchors(...)      // unchanged
export function centrePhaseCandidates(...) // unchanged
export function chooseCentrePlacement(...) // unchanged — Free-display pick only
export function evaluateWrap(measured: WrapMeasurement, policy: { mode: 'fixed'; allowanceMM: number } | { mode: 'auto'; capMM: number }): WrapEvaluation
export function inspectionConcessions(parity: ParityMeasurement, wrap: WrapEvaluation): Concession[]
export function reduceBandLadders(candidates: PlacementCandidate[]): BandLadder[]
export function applyCoverage(...), assignSizes(...)   // unchanged
```

`reduceBandLadders`: judge each candidate's `wrapMeasurement` with `evaluateWrap`; keep candidates that are parity-true and wrap-lawful → group by `magnetCount` → per count the smallest `sizeMM` → at that size keep all placements; Auto keeps the minimum `requiredFlapMM` and its ties → vertical eliminates horizontal among placements equal on centre, wrap, count and flap → publish counts strictly greater than the last published → a count is owned by the first band that accepts it and suppressed above. Typed band refusal when a band accepts nothing.

### 5.4 `engine.ts` — orchestration only

```ts
export function computeGrid(contour: Contour, requestedSizeMM: number, cfg?: GridConfig): GridResult   // Free/manual: Centre → four placements → one final seat/belt/Wrap measurement → Coverage/MagnetPlan output; Logic judges wrapMeasurement; candidates returned; display pick via chooseCentrePlacement; concessions measured
export function solveBands(sized: (evenSizeMM: number) => Contour, cfg?: GridConfig): BandSolveResult   // each even size once: computeGrid(sized(sizeMM), sizeMM, cfg) stored in gridsBySize; candidates → reduceBandLadders; `sized` is the bridge's existing offset-aware sizer
export function fitSizeInBand(solved: BandSolveResult, bandId: 1|2|3|4, rungIndex: number, layoutIndex: number): GridResult   // stored only; no re-solve
export function autoFlapInBand(sized: (evenSizeMM: number) => Contour, cfg: GridConfig, capMM: number): BandSolveResult   // the same solve with wrapMode 'auto'; no scan
```

`fitSizeInBand` reads the cached per-size `GridResult` and overlays `phaseMM`, `lattice`, `anchors`, `wrap`, `parityTrue`, `centreErrorMM` and `contactsMM = wrap.witnesses.map(w => w.outlinePointMM)` from the stored lawful layout and sets `concessions: []`; truth dots are produced only from returned witnesses on a lawful result — refusals draw none, and a positive whole-mm clearance is still a truthful witness when the applied flap reaches it; `pitchCentreMM`, `spotRadiusMM`, Centre evidence and `candidates` stay from that one cached size result. It performs zero geometry, Centre, Wrap, Coverage, contour-scaling or Logic calls; changing a rung chip changes only the selected stored layout. `solveBands` is the only production loop over `BANDS`/`SIZE_STEP_MM`.

Engine contains no law predicate, no rounding, no geometry arithmetic. Cost: Centre, seat and parity run for every placement at every even size; Wrap may be skipped only for a count already accepted at an earlier size. For a count not yet accepted, every placement at the current size is measured; when any passes, all co-lawful placements at that earliest size are kept and later sizes are skipped for that count.
