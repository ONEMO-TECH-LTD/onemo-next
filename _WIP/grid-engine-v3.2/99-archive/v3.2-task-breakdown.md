## T4 — CERTIFIED PLACEMENT  *(the real build)*

### T4.1 — the safe core  *(new `compute/safe-core.ts`)*
**Change:** exact-lawful-centre region as a first-class object.
**How:** Clipper2 `InflatePaths(-radius, round joins)` on the scaled contour in integer units,
then **shrink by the stated approximation epsilon** so the result is provably *inside* the true
region — false-negative-safe per the R3 contract. Holes handled by the same call.
**Verify:** every point of the returned region passes `distanceToPreparedContour ≥ r` on the
exact predicate · the tangency case (exactly r) is included · a 0.01mm intrusion is excluded.

### T4.2 — feasible translations  *(new `compute/feasibility.ts`)*
**Change:** replace "sweep origins and hope" with the exact set of lawful placements.
**How:** for a pattern with offsets `o₁…oₖ`, the legal translation set is
`F = ⋂ᵢ (SafeCore − oᵢ)` — translate the safe core by each offset and intersect, all in Clipper2
integer space. `F` empty ⇒ **certified infeasible**, not "not found".
**Verify:** the five adversarial cases meta measured — zero-area corridor found exactly ·
too-narrow corridor certified infeasible · concave notch yields zero false seats · starved
budget degrades to INDETERMINATE rather than inventing · ±0.01mm hairline seat found.

### T4.3 — the critical set
**Change:** the finite candidate set that certifies the optimum over a continuous region.
**How:** candidates = vertices of `F` + the canonical registration point projected into `F` +
the extremal points of `F` along each criterion's direction. Every candidate re-proved through
`computePreparedGrid(..., {construction})` — the existing exact door, on BVH-backed predicates.
**No sampled representative ever stands in for a region.**
**Verify:** A/B against the old sweep on the seven shapes — the sweep used **only** as a
falsification oracle (it may not find something we miss) · runtime measured and reported against
R3's provisional 16ms/50ms.

## T5 — THE GOVERNING COMPARATOR

### T5.1 — the region graph  *(new `compute/regions.ts`)*
**Change:** the measured structure that coverage and distribution require.
**How:** erode at several clearances (r, r+4, r+8, r+12) with the same Clipper2 path; extract
connected components at each level; per component record area, centroid, local width, vertical
position, and **persistence** (how many levels it survives). Pure measurement — every threshold
stays in the profile.
**Verify:** the bat's map reads head-mass / narrow connector / broad lower mass with **no shape
name in the code** · ear tips and neck drop out by measurement, per size · the existing
counterexample suite still passes.

### T5.2 — criterion descriptors  *(new `logic/criteria.ts`)*
**Change:** each rule becomes a named, versioned, independently testable function.
**How:** `coverage` (major regions holding an anchor) · `upperSupport` (material above the top
anchor line, mass-weighted) · `unsupportedExtent` (per-side wrap against the 12/24 switch, limb
exemption **returned as data**) · `peelLeverage` · `patternAdmission` · `distribution` (distinct
masses covered) · `balance` (evenness across all sides at once) · `count`. Each returns a value
plus its tolerance.
**Verify:** each descriptor unit-tested on a purpose-built synthetic shape where its answer is
known by construction.

### T5.3 — the comparator
**Change:** `better()` replaced by `compare(a, b, profile)` applying descriptors in the governing
order: legality → coverage → upper support → unsupported extent → peel → pattern → distribution
→ balance → fewer at equal support. `structureScore`, `isCorners`, the fit tier and the mass-axis
buckets all retire into descriptors or vanish.
**Verify:** constructed pairs prove each position (a candidate better only on rule *n* wins
against one better only on *n+1*) · every ruled canon frame holds · every moved answer is shown
to Dan with its frame.
