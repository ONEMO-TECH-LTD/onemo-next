### B8 · THE SECOND LOOK IS GIVEN ONLY TO LOSERS
`judgement.ts:1090` — `if (first.violations.length)`. A candidate that missed its own bracket gets the

search.**

would silently favour whichever ones happen to fail their brackets. You would be measuring a corrected
menu through an uncorrected comparison.
**Not a one-liner:** making it symmetric breaks two tests, one of them a behavioural law about one magnet
per lobe. Product consequence, so it needs Dan — which is why it was parked this morning and then
dropped.

`logic/judgement.ts:738-740`

**AND THE CORRECT BEHAVIOUR IS ALREADY WRITTEN AND UNREACHABLE** — `judgement.ts:566-572`:

*This is the P2/P7 collapse — the single largest ranking defect.* (@s62-lead)

### B2 · The frame lock — and it is a GATE, not a filter
`templatesForCell` is called at `judgement.ts:696`, **before the safe core is built and before any
feasibility or measurement.** A template the cell does not name is never measured at all — the shape is
not rejected, it is never examined. For a square-ish band-2 shape the cell admits `pair-diag`,
`pair-antidiag`, `square-48` and four corner-triangles. **`pair-v` and `pair-h` are not among them** —
and `pair-diag` is admitted only because its bounding frame happens to be 2×2, which is exactly why the
bat comes back diagonal. (@s62-lead, verified here.)

`logic/judgement.ts:238-241`
```ts
return calibration.templates.filter((template) => {
  const frame = templateFrame(template)
  return cell.frames.includes(`${frame.across}x${frame.down}`)   // ← exact string equality
})
```
**Fix:** capacity bound, not equality —
`frame.across <= cell.capacity.across && frame.down <= cell.capacity.down`.
Canon: *"capacity, never compulsory"* and *"the material may reduce it, never inflate it."*
*This is why a square-boxed bat can never be offered its vertical pair.*

depths**. That is not anatomy, and it is why B1 has nothing real to feed.

Canon PB §7.3 requires ten fields: major safe regions · marginal safe regions · terminal branches ·
material corridors · region area · centroid · local clearance · local width · vertical position ·
**persistence across nearby sizes** (today's `persistenceLevels` measures persistence across *clearance
levels* — same word, different question).
Canon PB §8 requires strong/marginal on **five** properties; today it is one (`judgement.ts:924`,
`clearance >= levels[strongLevelIndex]`).

**Everything downstream of this already exists.** Build it and P2, P7 and P7b wake up with no other
change.
