**Acceptance:** exact geometry core untouched · no missed lawful placement demonstrable against

### STEP 3 — THE GOVERNING COMPARATOR AND RESULT IDENTITY

Replace `better()` with the contract's versioned criterion descriptors in the product-base
order: **legality → major-region coverage → upper gravity-critical support → unsupported
extent → peel leverage → approved pattern → distribution across masses → balance → fewer
magnets at equivalent support.** Tight fit is applied through certified wrap facts (per-side
extent, max side, total, imbalance) **before** structure/spread — and the current `tier` is
**not** moved across: its definition is unsound (`allowed` ignores side flap entirely).

Result identity carries **window/scale + registration + profile + artifact**, not topology
alone. One certified optimum per distinct governed window step; **equal-count optima remain
valid** when window or placement identity differs; `optionsPerBand` caps presentation only
after the complete ordered set exists.

**Acceptance:** the count ladder is gone · no cross-band truncation (each band certified over
its own governed domain; echo suppression applied only after each band's set is complete) ·
no fallback manufactures an optimum — the contract's indeterminate/failure result is returned
with its reason, surfaced in the UI.
