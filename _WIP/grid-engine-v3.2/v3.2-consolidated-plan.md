**THE CONTRACT IS NOT UNTESTED — and its one implementation failed on performance**
*(meta C3, MATERIAL).* GPT's build **was** this contract. Meta's R6 audit measured it on the
real bat trace: `certifySizeSolution` returned **`DECISION_INDETERMINATE` at 60mm (23.3s)** and
**at 96mm (54.9s)**, with preview solves of **18–36s across all seven shapes**, because that
implementation carried **no spatial acceleration**. Adopting the contract does not inherit
speed; the contract is a correctness architecture, and its performance is ours to earn.

**WHY THE BOUNDARY IS WHERE IT IS** *(meta C4 — carry the positive evidence).* The same
adaptive architecture survived five independent adversarial attacks in R6: a zero-area corridor
found exactly · a too-narrow corridor certified infeasible (not guessed) · the concave notch
that broke Grok's kernel produced **zero false seats** · a starved budget degraded honestly to
INDETERMINATE rather than inventing an answer · a hairline ±0.01mm seat found. That is why we
adopt this architecture and replace the heuristic flood — it is attack-proven where ours is not.

**Acceptance:**
1. exact geometry core untouched;

3. **feasibility search runs on v1's accelerated predicates** — the BVH and y-interval trees

   not a Dan ruling* (meta provenance note).
