### T3 · The pure pipeline replaces the old path

**Why.** The contract above. Today the engine is a size sweep with a hidden max-count winner:
on a 168mm square it builds four lawful registrations — 16, 12, 12, 9 magnets — and keeps only the
16 before wrap sees any of them, which Dan's brief forbids by name.

**Minimal diff, one change, no dual path.**
- `grid-magnet.ts` becomes the one door: segment → classify → match → wrap → an **unsorted attempt
  ledger**. No sort, no default landing, no witness, no judge.
- Classifier: ordered frame from the **union of all live masses** — never the outer box, never the
  governing mass. Ceiling derived from the live band table; the `1|2|3|4|5` type, the countdown and
  the clamp go. Returns **every** candidate on the frame with its evidence, marked ambiguous:
  8 of 24 frame groups are cross-class, so a single winner would be an invented filter.
- Matcher: candidates by band + ordered frame, returning `{ entry, view }` — one canonical record,
  the matcher says which way round. Fixes the landscape shape that cannot receive a portrait layout.
  `ROTATION_VIEWS` / `D4_VIEWS` proved through `transformLayout` before use.
- Placement: the **full** rigid population enters `wrapGroup`, which already computes the exact set
  of lawful origins. A null wrap is evidence — never permission to drop a node.
- `units/centring` stays as the governed anchor: `heldAt`/`pickOrigin` only break ties among origins
  that are already lawful, so it filters nothing.
- Deleted in the same change: `grid-magnet-wrap-compute.ts` (sweep, ladder, dedupe, judge
  composition), `units/judge.ts`, `defaultLanding`, `registerLayout` and its four-parity winner,
  `applyCoverage`, `fallbackRevealSizes`, `bestSeatedCandidate`, `grid-magnet-class.ts` and
  `shapeFamilyOf`, `grid-magnet-compute.ts` and `grid-magnet-logic.ts`, both stride decimators, the
  dead two-magnet floor, the silent invalid-band fallback, both contact thresholds, and the padding
  resolved at eleven sites — one resolver at the door returning the released 12, no unit defaulting
  or clamping.
- Shell: one card per attempt — class, frame, requested/placed/omitted, wrap size, the band it
  actually landed in, outcome. Auto-select only when exactly one attempt wrapped in the requested
  band.

**Done when.** The bench shows the raw attempt list for a shape whose right answer Dan knows, with
nothing ordering it · no production reference survives to any deleted symbol · full suite, typecheck
