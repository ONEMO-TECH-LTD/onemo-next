# v3.5.6 Pipeline

## Step 1 — Segmentation, legal area, class

Once per shape, at load, size-free. Scale never changes it.

1. Erode the traced outline by 12mm. What remains is the legal area — where a magnet centre
   may sit.
2. Measure the legal area: its islands, their masses, and the segment box.
3. Read the class from the segments: family (square · round · triangle) and kind, plus the
   frame per band.
4. Show the result in the admin panel — name of class and kind — for validation by eye.

### Units

| Unit | Does | Lives | Status |
|---|---|---|---|
| Erosion + island tracer | 12mm erode → legal-area islands, masses, deep points, boxes | `safeSegments` · grid-magnet-compute | have |
| Load-time bake | runs the measurement once per shape, stores it, scales it | `anchorFnFor`/`anchorBakeOf` · worker + grid-magnet-logic | have |
| Segment box retention | keep the legal area's box from the bake measurement | bake store | missing |
| Axis classes + frame | lines per axis from the lattice; frame per band | `axisClassOf`/`classifyShape`/`classFrameNodes` · grid-magnet-class | have, unconnected |
| Family + kind | square · round · triangle, from fill + corner occupancy | `shapeFamilyOf` · grid-magnet-class | have, unconnected |
| Class in the bake | classifier reads the bake's measurement, result stored | bake → class | missing |
| Class in the response | family/kind/frame/segment box on every solve reply | worker reply | missing |
| Classifier panel | Family · Kind · Frame · Segment box, admin fold | page | missing |
