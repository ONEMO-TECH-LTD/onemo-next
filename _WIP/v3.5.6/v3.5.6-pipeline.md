## The pipeline

### At shape load — once, size-free

1. **Trace** the outline.
2. **Segmentation** — 12mm erosion defines the legal area; its islands, masses and box are
   measured once.
3. **Classification** — the class is read from the segments (family + kind + per-band frame).
   Displayed in the admin panel as name of class and kind for validation by eye.
4. **Centring** — the class points at its pre-decided centring mode, then the centre SPOT is
   computed once and fixed — a property of the shape, scaled linearly ever after. Scale never
   changes centre, segments or class.
   - **OPEN: the class → centring-mode table.** Not decided. To be ruled by Dan per class,
     with exemplars side by side on the bench.

### At band click

5. **Layout** — the band provides layouts from precomputed presets per class
   (Dan: "shapes are undefined cause they are random — segment recognises and classes the
   shape; the layouts for each class are pre-sets precomputed variations"; bands × presets =
   "100% certainty… can precompute all"). The single and the pair are tried in every band
   regardless of class. Magnets exist only at lattice nodes.
   - **OPEN: the preset library's form and content** (the literal table) — to be reviewed by
     Dan before it becomes law.
6. **Wrap seals last** — the exact Clipper contact solve. The layout starts on the centre and
   shifts ONLY the exact mm the wrap demands — the cove-dip ("shift... by the exact mm
   required no less no more"). Wrap is the law: a variant that grows the shape to stay pinned
   on the centre is not a wrap; a shown state with slack is not a wrap.
7. **Band membership** — a layout whose contact size falls outside the band belongs to another
   band and is not offered here.
8. **Fine-tune** — the small adjustment: a couple of mm of size may be spent when it buys the
   layout closer to centre AND it stays wrapped ("it could have computed the small adjustment
   to make it wrap and be closer to center"). Any centring start must fine-tune to the same
   required result — wrap / closest to centre / no flap ("I don't even have to switch
   centering — it must be the same because the fine-tune must make it so").

### Protection

9. **The 96mm perimeter law** — "unheld between extreme perimeter is fine, edges unprotected
   is bad, every minimum 96mm of perimeter must be pinned." Gravity first: "top flap is
   priority always."
10. **The class is the anti-flap guard** ("the class itself must be it") — enforcement by
    construction. **If not enough**: "use the clipper2 fix that subtracts and ellipses, show
    unprotected edge perimeter and forced to place magnet there with relevant wrap and layout."
11. **The 1–2 magnet exception** — "the centering or diagonal positioning of pairs to protect
    balance and edges"; "the pair and single magnet must be tried no matter the class."
    - **OPEN: where the exception stops** — a bare pair must not land in a high band whose
      class demands more (observed failure); the exact scoping rule is not ruled.
12. **Coverage dominance** — an offer with unprotected areas is not an option when a same-size
    offer covers them; there is no enforced magnet count anywhere — count is always an output.
13. **Best class match** — the offer that best matches the class outranks patched or
    discovered variants ("why do we have these two options if the 148mm provides the best
    matching to the class").
14. **Landing** — rule 4 (08-24): among lawful offers prefer the tight solution closest to the
    centre; centring may cost size only within the ruled bound.
    - **OPEN: the full landing order** beyond rule 4 (how class match, count and shift rank).
