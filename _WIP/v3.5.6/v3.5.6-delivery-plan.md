## P0.1 — One layout per frame, right frames per spacing, bands computed once · landed `016292ba`

The library publishes one population per frame: full coverage. Square and rectangle are canon;
diamond and triangle are presets. Frames derive from the board in millimetres at the asked lattice.
The band has one owner and the page stops computing it. Catalogue v3, band never null.

- **AC — canon:** one population per frame, named `full` or `single`; no `perimeter`, `corners` or
  `perimeter-96` published by the library.
- **AC — pitch:** frames stop at 17×21 at 24mm, 9×11 at 48, 5×6 at 96; no record's legal box exceeds
  384×480mm.
- **AC — band:** every published record carries a band; an absent band throws at the producer; the
  page reads `materialized.bandId` and computes nothing.
- **AC — chips:** every frame chip reads its band at the asked pitch.
- **Evidence:** 24mm 254 records (17/204/9/24) · 48mm 92 (9/54/5/24) · 96mm 47 (5/15/3/24) · zero
  unbanded · zero over-board · `tsc --noEmit` clean · `eslint src/lib/effect/library
  --max-warnings 0` clean.
- **Known and stated:** the suite is red at this commit. P0.2 closes it. The commit says so.

## P0.2 — The tests match the library we now have

36 tests assert a contract that no longer exists; a red suite gates nothing after it. Rewrite the
real invariants, delete the tests of retired vocabulary — **delete, not rename**.

- **AC — invariants kept:** frame sets derived from the pitch-aware limits; one population per frame;

- **AC — the numeric gate:** the released-number scan is deleted **with its semantic replacements in

  ownership.
- **AC — orphan:** `symmetryClosure` is deleted; my removal of the 96mm triangle sampler was its only
  caller.
- **AC — zones:** `canon.ts` sits in zone 2 of the import matrix.
- **Evidence:** `npx vitest run` green · `tsc --noEmit` clean · `eslint src/lib/effect
  --max-warnings 0` clean · catalogue oracle regenerated against the v3 producer with its add-record

## P2.1 — Read the shape, say which grid it is

Today it measures the outer outline's box, counts to five and clamps, and its only consumer is a
display readout — delete it and every answer is identical.

- **AC — measurement:** the ordered frame comes from the **union of all live masses**; never the
  outer box, never the governing mass. A 30mm dead arm and a 50mm usable one read 3×3 and 3×6.
- **AC — ceiling:** derived from the live band table. The `1|2|3|4|5` type, the countdown from five
  and the frame clamp are gone. There is still a ceiling — it is the board's, not a typed number.
- **AC — honesty:** returns **every** candidate on the frame with its evidence, marked ambiguous.
  8 of 24 frame groups are cross-class, so a single winner would be an invented filter.
- **Evidence:** the limb pair separating 3×3 from 3×6; a frame above the old five classifying; a
  cross-class frame returning more than one candidate.

`catalogueCandidates` has no production caller and filters on the invented `fill < 0.68` family.

## P2.3 — One way in, runs without a browser, old search deleted

One change, no dual path. This is the task that makes the pipeline real.

- **AC — the door:** `grid-magnet.ts` runs segment → classify → match → wrap → an **unsorted list of everything it tried**. No sort, no default landing, no witness, no judge.
- **AC — headless:** that door is callable from a plain test with no browser. The worker becomes
  transport and cache; the page reaches the engine through an adapter. This is the lane's stated
  deliverable and it is what makes "test it" mean something other than clicking the bench.
- **AC — placement:** the full rigid population enters `wrapGroup`, which already computes the exact
  set of lawful origins. A null wrap is evidence — **never permission to drop a node**.
- **AC — centring kept:** `units/centring` supplies the governed anchor. `heldAt`/`pickOrigin` only
  break ties among origins that are already lawful, so it filters nothing.
- **AC — the old lane gone:** zero production references to `grid-magnet-wrap-compute.ts`,
  `units/judge.ts`, `defaultLanding`, `registerLayout` and its four-parity winner, `applyCoverage`,
  `fallbackRevealSizes`, `bestSeatedCandidate`, `grid-magnet-class.ts`, `shapeFamilyOf`,
  `grid-magnet-compute.ts`, `grid-magnet-logic.ts`, both stride decimators, the dead two-magnet
  floor, the silent invalid-band fallback, both contact thresholds.
- **AC — padding:** one resolver at the door returning the released 12. No unit defaults it, none
  clamps it. It is resolved at eleven sites today, each of which also raises a smaller value to 10.
- **Evidence:** a plain no-browser test returning that list, pasted · `grep` output proving each
  deleted symbol has zero production references, by name · the 168mm square showing **four**
  registrations where it shows one · suite, typecheck and scoped lint clean.

## P2.4 — The bench shows every layout found, unsorted · **DAN GATE**

Removing what Dan can see is his call, not ours.

- **AC:** one card per attempt — class, frame, magnet count, wrap size, the band it actually landed in,
  outcome. **No "omitted" field:** the MVP hands wrap the full population and a null wrap is evidence, so
  nothing removes a node and a count of removed nodes would have no producer. A field with no producer is
  where an invented filter reappears.
- **AC — one path:** the manual and band controls run the same pipeline. Product law §1: *"Free/manual and
  automatic/band solving use the same inputs, laws and verdict. Manual is not a bypass."*
- **AC:** auto-select only when exactly one attempt wrapped in the asked band.
- **AC:** no ordering, no default pick, no control the engine does not read.
- **AC — the duck check:** Dan's own acceptance from the brief is 3 magnets in the head at ~143mm
  not the neck at 125, 4 as a pair per mass at ~147, 6 as three stacked pairs at ~192. The MVP has no
  ranking so it cannot *pick* those — the check is whether each one is **present in the list at
  all**. If it is not, no ranking added later can produce it. This is a check on the MVP, not a
  deliverable of it; the full acceptance waits for ranking.
- **Evidence:** the exact tree served, commit named, swept across pitches, classes and bands, with
  captures. Per shape: the list, and where Dan's answer sits in it.
