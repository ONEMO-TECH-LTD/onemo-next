## Increment 2 — complete three-law vertical slice and cut-over

Files: existing magnetic-grid Compute/Logic/Engine/bridge/worker/UI and focused tests only; no new runtime module.

1. Move the legacy Voting one-cell registration walk into Compute, driven by `registrationStepMM`. Remove its scoring, max-count and winner behavior.
2. At each registration enumerate only finite Spec-enabled lattice window/sub-window and population templates. Record stable population ID, registration ordinal and sorted lattice-index set. Do not generate arbitrary subsets.
3. Run the existing Centre measurement once per size. For every chosen layout, Logic admits Centre only when the selected layout-region balance point matches the governed anchor on the configured ruler. Existing Centre modes/governors remain unchanged.
4. Compute the selected layout's ruled group region and report complete-boundary containment plus four outer overhangs. Logic applies configured Fit and recommendation order. Coverage is applied only after admission to choose the returned population; MagnetPlan changes diameters only. Neither changes Centre/Fit truth.
5. Use one internal `inspectSize(input, config)` for Free/manual and band solving. Engine visits every configured size exactly once and never supplies a second law path.
6. Return `CountTier { magnetCount, layouts, recommendedLayoutId }`. Each `LawfulLayout` retains its own `sizeMM`, population ID, registration ordinal, lattice indices, render state and evidence. Logic groups after the full configured walk, keeps the first lawful occurrence of each scale-independent layout identity, sorts counts ascending within each independent band, preserves ties and marks one recommendation.
7. Worker caches the complete solve and contours by size. Tier/layout selection is lookup-only. UI renders every count tier, every layout and each layout's own size.
8. In the same commit delete the v3.5.4 four-placement-only population, per-disc/minTouch admission, count-only identity, cross-band ownership and superseded score/winner paths. Comparison-tab implementations remain intact.

Gate: Dan's manual cutout placement is found automatically; smaller and larger lawful sub-layouts coexist; same-count layouts at different sizes survive; square/pair/diagonal/sparse/triangle/L/hole/real-cutout fixtures pass; Coverage/MagnetPlan mutations cannot alter admission; configured steps alter only their visited/enumerated sets; stored switching performs zero Compute calls.
