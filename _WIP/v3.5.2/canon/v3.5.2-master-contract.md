## 1. The ruler (Dan, 2026-08-23)

- **No law measurement is finer than 1 mm.** Sizes, flap, air, concessions: whole millimetres. A measured air is converted to the ruler exactly once, in Compute: `rulerMM = floor(max(0, airMM) + 0.5)` — `[0, 0.5)` reads 0, `[0.5, 1.5)` reads 1. Nothing below the ruler decides a law; nothing below the ruler is displayed as law. (Reading applied to Dan's ruling: an air the ruler cannot see is not a measurement, so it is not a gap. The alternative reading — any positive air reads 1 — is one constant; Dan may flip it.)
- **Shape sizes are even millimetres** (24, 26, 28 …). This rules the size ladder only; supplied contour coordinates, Centre outputs, phases, lattice nodes and mesh samples may stay fractional internally — they are measured, never ruled.
- Consequence: no exact rationals, algebraic numbers, irrational rung sizes, certificates, tolerances or new quanta enter Law policy. Ordinary double-precision geometry, converted once to the ruler, is the law's instrument. The frozen Centre path keeps its internal 0.001 mm integer seat prescreen as binary geometry (it selects placements; it is not a law value and never enters policy).

## 2. The three laws

1. **CENTRE** — at each even size, derive one governed centre from the scaled shape alone (Box, Core, Weight, Deep, Top, Masses with governor — the existing numeric ruler, unchanged), place the lattice rigidly by parity (odd line count: node on the centre; even: gap on it), and consider all four parity placements. The centre may change with size; it never changes because magnets landed.
2. **WRAP** — every seated disc must first be legal against the complete outline (outer and holes); then every perimeter-belt disc must lie within the flap: its air to the outline is measured and converted to the ruler; lawful when that whole-mm air ≤ flap. Seat and Wrap are opposite bounds on the same distance (`d ≥ r` to seat; `d ≤ r + flap` to wrap) measured on the same geometry. `0` = the disc is seated and its air reads 0 on the ruler. Auto returns the smallest whole-mm allowance that makes the layout lawful, never a scan.
3. **MAGNET-QUANTITY SCALING** — in each band, evaluate every even size and all four placements; publish each next available magnet count once, at the smallest even size where a placement with that count is centred and wrapped. Counts strictly increase (jumps are valid). A count accepted in a lower band never reappears above. Every candidate size is evaluated; coverage over the even-size ladder is complete by construction. No size between even sizes is ever followed, searched or published.

Tie rule: among placements equal on centre, wrap, count and flap, vertical eliminates horizontal; remaining ties are all returned. No score, weight, fallback or hidden winner anywhere. Refusals are typed; fixed-size/manual inspection returns measured whole-mm concessions.

### 5.2 `compute.ts` — geometry only

- `seat.ts`: `bbox`, `latticeAt`, `makeSeatPredicate` unchanged as the frozen Centre path's placement prescreen (float + 0.001 mm integer kernel, outer-only; internal geometry, not a law value), circle path deleted, `measureCentrePlacements` (all four), `splitPerimeter`, `measureExtremeCorners`, `edgeDistMM`, `pointInMaterial(contour, p)` (outer + holes, float winding), `scaleContour(base, evenSizeMM)`.
- `centre-evidence.ts`: `safeSegments`, `centroidOf`, `measureCentreBranches` — unchanged.
- `wrap-measurement.ts` (renamed from `contact-root.ts`): `measureWrap(contour, seated, belt, spotRadiusMM): WrapMeasurement` — the supplied segments, outer + holes, are the sole geometry; (1) legality for **every** seated disc: `pointInMaterial` and `d ≥ r` against outer and every hole, plain double arithmetic, no quantum — any illegal seat → `invalid-seat` refusal before any air is measured; (2) for each belt disc, nearest distance to every outer and hole segment (`edgeDistMM`), air = distance − radius, then — only after seat validity — `airMM = floor(max(0, air) + 0.5)`; `requiredFlapMM = max airMM`; witnesses = every belt disc with its nearest outline point and `airMM`.
- `identity.ts`: `contourIdentity(contour)` = canonical JSON of the ordered coordinates (no hashing library); `boundaryTruth` = `{ rule: 'supplied-final-contour', contourIdentity }`.

Conversion to the ruler happens exactly once, in `measureWrap`; fixed, Auto, Free/manual and the band walk all consume that one integer. No other place rounds, clamps or tolerates.

### 5.3 `logic.ts` — the three rules, integer comparisons only

Logic receives self-contained measurements and returns decisions. `evaluateWrap(measurement, policy)` is the one judgement; `computeGrid` (Free/manual) and `reduceBandLadders` (band) both call it on the same `WrapMeasurement` shape, so fixed, Auto, manual and rung can never disagree. Its scaling inputs are the integer `sizeMM`, the integer `requiredFlapMM`, parity evidence, populations and identities; native integer comparison is authoritative because the ruler conversion already happened in Compute. Logic imports nothing from compute.

```ts
export function governMass(...)            // unchanged
export function centeringAnchors(...)      // unchanged
export function centrePhaseCandidates(...) // unchanged
export function chooseCentrePlacement(...) // unchanged — Free-display pick only
export function evaluateWrap(measured: WrapMeasurement, policy: { mode: 'fixed'; allowanceMM: number } | { mode: 'auto'; capMM: number }): WrapEvaluation
export function reduceBandLadders(candidates: PlacementCandidate[]): BandLadder[]
export function applyCoverage(...), assignSizes(...)   // unchanged
```

`reduceBandLadders`: judge each candidate's `wrapMeasurement` with `evaluateWrap`; keep candidates that are parity-true and wrap-lawful → group by `magnetCount` → per count the smallest `sizeMM` → at that size keep all placements; Auto keeps the minimum `requiredFlapMM` and its ties → vertical eliminates horizontal among placements equal on centre, wrap, count and flap → publish counts strictly greater than the last published → a count is owned by the first band that accepts it and suppressed above. Typed band refusal when a band accepts nothing.

### 5.4 `engine.ts` — orchestration only

```ts
export function computeGrid(contour: Contour, cfg?: GridConfig): GridResult        // Free/manual: Centre → four placements → seat → Coverage → Wrap; candidates returned; display pick via chooseCentrePlacement; concessions measured
export function solveBands(base: Contour, cfg?: GridConfig): BandLadder[]          // for band, for even size: computeGrid(scaleContour(base, size)).candidates → reduceBandLadders
export function fitSizeInBand(sized, cfg, bandId): { rungs: Rung[]; pickIdx: number; grid: GridResult }   // from the stored ladder; no re-solve
export function autoFlapInBand(sized, cfg, bandId, capMM)                            // same walk with wrapMode 'auto'; no scan
```

Engine contains no law predicate, no rounding, no geometry arithmetic. Cost: Centre, seat and parity run for every placement at every even size; Wrap may be skipped only for a count already accepted at an earlier size. For a count not yet accepted, every placement at the current size is measured; when any passes, all co-lawful placements at that earliest size are kept and later sizes are skipped for that count.
