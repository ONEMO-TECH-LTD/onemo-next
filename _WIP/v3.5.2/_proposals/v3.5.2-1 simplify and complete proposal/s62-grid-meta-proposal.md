## Bounded scaling algorithm

1. Walk each band in increasing size using the existing selected-Centre execution path. The walk discovers only observed count/layout changes.
2. For each newly observed count/layout, generate all locally relevant belt-disc/supplied-segment binding roots for that layout. Do not choose one arbitrary contact.
3. Solve those roots with the retained rational/quadratic kernel. Exact algebraic handling is limited to final candidate seating/contact/Wrap evidence and the stored result; it does not replace Centre, its 2mm mesh or UI geometry.
4. Re-run the complete existing Centre, four placements, seating and cleared Wrap at each solved candidate. Full Wrap—not the generating equation—decides whether every belt disc is lawful.
5. If exact-root recomputation changes the count/layout, discard that candidate and continue discovery. Do not add recursive stability or cycle machinery unless a named product fixture proves it necessary.
6. For each count strictly greater than the previously published count, retain its earliest accepted candidate and every co-lawful placement.
7. Suppress a count already owned by a lower band. Fixed and Auto reuse the cleared exact worst-belt law.
8. Worker/cache stores the complete accepted result. UI uses its report decimal for display while retaining exact scale/witness data unchanged.

Approximate size, scan quantum and displayed decimals never decide Wrap legality.
