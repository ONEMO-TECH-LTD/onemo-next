# Selection examples — what the right answer LOOKS like, per band

Dan's walkthrough of the engine's proposed placements (greens), one band at a time. Each band folder
carries the screenshots and a `description.md` stating what the expected result must look like and
which law selects it. These are the acceptance pictures for L20 (selection: gravity first, then the
tight wrap, over enumerated placements) — the engine's chosen answer must match these by eye, per
L19's acceptance bar: "the marked answer must be the one a person would have chosen".

Folders follow the band ranges: sizes run from the band's span up to the next span on the 12mm step.
Rows land as Dan walks them. Do not invent the unwalked rows.
