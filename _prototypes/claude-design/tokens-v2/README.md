Generated by the scan-driven converter (`tools/ds-pipeline/build-scan.mjs`) from the
canonical Figma source above.

**780 tokens, every one verified correct** across all five outputs, light + dark —
source-grounded: colour by RGB round-trip, `rem`/`em`/`ratio` by independent arithmetic,
fluid clamps re-derived from source. Architecture + verification regime live in
`11-design-system/token-system-blueprint.md`.

**Fluid model (v2.3):** nominal exact at **base 402** (modern iPhone), scales *down* to **floor 320** (WCAG 1.4.10 reflow width, flat below), up to **max 1440**. Every fluid token is emitted with `vi` (viewport-inline) at `:root` **plus** a `cqi` (container-inline) twin under `[data-fluid="container"]` — wrap a subtree with `container-type: inline-size` + `data-fluid="container"` to make its fluid tokens scale to that container instead of the viewport (e.g. the editor as a 560 column, or a mobile/desktop dual-view).

| File | Use |
|---|---|
| `tokens.css` | **Primary** — build with `var(--sem-*)`. Has `:root` + `[data-theme="dark"]`, full prim→alias→semantic `var()` cascade. |
| `tokens.light.json` / `tokens.dark.json` | DTCG full graph — the reference for exact token names + values. |
| `tokens.tailwind.css` | Tailwind `@theme` variant. |
| `tokens.ts` | React (camelCase nested, `var()` refs). |
| `tokens.liquid` | Shopify Liquid (snake_case). |

Type is fully fluid: font-size + paragraph-spacing clamp; line-height (ratio) and
letter-spacing (em) ride the font.
